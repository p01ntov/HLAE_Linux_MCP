# CS2 Camera Studio

Редактор для мувиков и хайлайтов из демок CS2 на Linux. Помогает выбрать ракурс
для фрага, провести камеру по карте и подготовить шот для монтажа.
Камеру настраиваешь прямо в игре.

## Что можно сделать

- Снять пролёт по карте: задать путь камеры и настроить, где она разгоняется,
  поворачивает или останавливается.
- Показать момент с другого ракурса: приблизить камеру к действию или
  построить её движение вслед за игроком.
- Подготовить материал для монтажа: добавить эффект объектива, сохранить
  MP4 со звуком или PNG-кадры для слоумо с захватом до 1000 FPS.

## Запуск

Linux x86_64, CS2 и FFmpeg.

Скачай [AppImage 0.1.15](https://github.com/p01ntov/CS2CameraStudio/releases/tag/v0.1.15)
(предварительная сборка) и запусти:

```sh
chmod +x CS2-Camera-Studio-x86_64.AppImage
./CS2-Camera-Studio-x86_64.AppImage
```

Перед запуском закрой обычную CS2. Выбери `.dem` и нажми **Open Demo + Editor**.
Чтобы сохранить проект и выйти, используй **Safe exit**.

[Документация, MCP и сборка из исходников](https://github.com/p01ntov/CS2CameraStudio/wiki).
